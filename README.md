# CODER

En esta entrega se realiza la implementacion en express de carros de supermercados, al cual se le pueden añadir y quitar productos, los cuales se pueden tambien eliminar de la lista y actualizar. Los carros se crean con un id autogenerado al realizar el post, y luego se le agregan productos con el id del carro y del producto, se verifica que el producto exista en la lista de produtos, y se verifica que si ya existe el producto en el carro solo se incrementa o decrementa su cantidad. tambien se puede eliminar el carro por completo con su id.
